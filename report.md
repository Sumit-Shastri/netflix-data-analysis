# Netflix Data Analysis Report

## Objective

Analyze Netflix's content library using Python and Pandas to discover trends and answer business questions.

---

# Dataset

- 8807 Rows
- 12 Columns

---

# Data Cleaning

Performed the following:

- Removed duplicate rows.
- Filled missing values in:
  - Director
  - Cast
  - Country
- Dropped rows with missing Date Added, Rating and Duration.
- Converted Date Added into datetime format.

---

# Exploratory Data Analysis

Performed analysis on:

- Content Type
- Countries
- Release Years
- Ratings
- Genres
- Directors
- Actors

---

# Conclusion

Netflix's library is heavily dominated by Movies and content produced in the United States. International Movies represent the largest genre, while TV-MA is the most common audience rating. The analysis demonstrates how Python and Pandas can be used to clean, explore, and extract meaningful business insights from real-world datasets.
